# The Wealth Bible: Real Estate Investor Edition

A free, mobile-first study system for building a rental portfolio with the BRRRR method (buy, rehab, rent, refinance, repeat).

**Open it:** https://spqrtavera-lab.github.io/brrrr-mastery/
On iPhone: open in Safari → Share → **Add to Home Screen**. Works offline.

## What's inside
- 18 modules: how wealth works, deal math, rehab, landlording, other people's money, business credit, the tax code, entities, marketing, sales, contracts, AI, daily habits, scaling, plus Florida and Ohio guides
- Spaced-repetition flashcards, optional quizzes, Listen (text-to-speech) on every chapter
- 8 calculators: BRRRR deal analyzer, income replacement, mortgage, net worth, depreciation, HELOC, marketing budget, rehab pricer

## Editing content
Each module is one file in `content/` (format in `content/FORMAT.md`). Bump the cache version in `sw.js` after changes so phones pick up the update.

Education only. Not legal, tax, or investment advice.
